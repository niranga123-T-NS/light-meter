Lighting Operations System
Sales Person – Data Entry, Step by Step
For Assistant Sales Managers (Building Lighting and Infrastructure Lighting) · https://dimo-lighting-ops.vercel.app
The order to enter data Customer → Project → Weekly plan → Check in at the visit → Visit report → Inquiry → Keep the project up to date. Button names are shown like this; menu paths like Projects → + New project.
Daily routine Morning: check My Day · At every visit: check in · By 20:00: finish visit reports · Saturday 13:00: submit next week's plan.

1Add the customer (once per organization)

Customers → + New customer

  1. Organization name, Type (visit category), Phone and Head office address.
  2. First unit / department (optional), e.g. "Engineering Division".
  3. Contact (optional): Name, Designation, Phone and Email.
  4. Tap Create customer. If Possible duplicates appear, tap Use this on the matching customer instead.

2Create the project

Projects → + New project (or from inside a visit – see step 4)

  1. Project name as Customer – Project – City, e.g. "ABC Hotels – Beach Resort – Galle".
  2. Project type: only your own types are listed.
  3. Customer (use + New customer if it is missing), City, Location / address. Optionally tap 📍 Use my current location as the site.
  4. Stage and value: Project stage, Duty status (sets LKR or USD), Estimated project value and Estimated lighting value.
  5. Project term (mandatory): enter Expected duration to order / award in months. The term is suggested automatically; changing it needs a reason.
  6. Tap Create project. If a similar project exists, tap Use this project, or confirm it is a different project and give a reason.

3Plan next week (submit by Saturday 13:00)

  1. Plan → Open next week's plan.
  2. Tap + Add visit: choose the Day, Time slot, Normal or Tender, the project, the customer, Visit category and Planned objective. Tap Add to plan.
  3. Repeat for every visit, then tap Submit plan for approval. SM Projects approves it or returns it for changes.

4On the day – check in at the site

  1. On My Day tap Check in next to the planned visit (details fill in automatically). For a visit that was not planned, tap Check in to a visit.
  2. Allow location access. GPS is recorded only at check-in and check-out.
  3. Choose Normal or Tender, the Project, the customer, Visit category, Primary objective and up to 3 Secondary objectives.
    New project? In the project search tap + Create project; after saving, the app returns to the visit with the project selected.
  4. Either tap Check in (report later), or fill in the report now and tap Save visit report.

5Visit report (same day, by 20:00)

  1. Discussion summary (at least 30 characters – the keyboard microphone can be used) and Outcome.
  2. Competitors mentioned, Brands specified, Estimated project value and Estimated lighting value.
  3. Next action and Next action date.
  4. Tender visit: Tender activity, Tender number and Closing / opening date.
  5. Add photos or documents if needed, then tap Check out and save report.

6Raise an inquiry (design or quotation needed)

On the visit tap Convert to inquiry, or on the project tap + Inquiry.

  1. Project and customer: already filled in.
  2. Route: design + estimation, estimation only, or design only.
  3. Scope: Scope description, Areas / spaces, Design scope and Tender or submission type.
  4. Client solution expectation: Solution level, Preferred brands, Manufacturing origin, Budget indication and Approved makes list.
  5. Dates: Customer deadline, Design required by and Quotation required by.
  6. Tap Save draft and continue, attach drawings and the BOQ, then tap Submit inquiry.

7Keep the project up to date

  1. On the project page update Stage, Win probability (a reason is needed outside the normal range), Award date and Lighting value.
  2. Answer Review status prompts for dormant projects: active, on hold, lost or cancelled.
  3. Follow up the quotation and record the result: won or lost.

+Also during the week

  • Reschedule, Cancel or Missed on planned visits – a reason is required and every change is logged.
  • My Debtors: add follow-up comments on overdue customer payments.
  • Samples: request samples and return them on time.
